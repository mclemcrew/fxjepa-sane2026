# Listening clip licences

Every clip on this site is a 10 s excerpt of a Free Music Archive track, split into stems and processed by us. The dry, processed and predicted versions are derivative works (remixes) of the original recording. Each track is released under the Creative Commons licence named below; the licence text is quoted verbatim from the FMA dataset metadata (fma_metadata/tracks.csv), and each licence link and FMA page is the one shown on the live FMA track page, checked on 26 Oct 2026. Where the dataset says only "Attribution", the FMA page links CC BY 4.0. Changes made: excerpted, split into four stems, each stem processed through an effects chain and re-summed, level-normalised and MP3-encoded.
